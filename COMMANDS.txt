git init - инициализация репозитория
cd .git - войти в скрытую папку
cat config - вывести содержимое файла config (настройки репозитория)
git status - показывает состояние рабочей директори и проиндексированных файлов
git log - выводит историю коммитов
git commit -m ... - создает коммит с указанным сообщением
